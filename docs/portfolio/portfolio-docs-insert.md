## 시스템 아키텍처

![시스템 아키텍처](images/01-architecture.png)

**아키텍처 설계 이유**

- **모델 검증**

추론 코드나 모델을 바꿔 배포할 때마다 GitHub Actions가 이미지 빌드, 정확도 평가, Lambda 버전 전환을 순서대로 실행합니다.

- **변환 대조 (이미지 빌드 중)**: 모델을 ONNX로 변환한 직후 출력을 PyTorch 모델 출력과 비교합니다. 차이가 허용 오차를 넘으면 빌드를 멈춥니다.
- **정확도 평가 (빌드 후, 배포 전)**: 전처리가 다르면 같은 모델도 정확도가 달라지므로, 고정 검증셋 2,024품목을 서비스와 같은 전처리로 평가합니다. 직전 모델보다 정확도가 떨어지면 서비스가 호출하는 Lambda 버전을 바꾸지 않습니다.

![모델 파이프라인. 빌드, 고정 검증셋 평가, Lambda 버전 전환](images/08-model-gate-actions.png)

### 결론

- **INT8 차단**: 가장 빠른 INT8 양자화 모델(164ms)은 오차 3cm 안에 드는 품목 비율이 62.5%에서 22.6%로 떨어져 배포되지 않았습니다.
- **배포 모델**: 정확도 평가를 통과한 경량화 모델이 없어, 양자화하지 않은 ONNX 모델을 배포했습니다.
