## 문제 1. 박스 추천이 택배로 보낼 수 없는 박스를 만든 문제

### 문제 배경

- **현업 피드백**: CJ 현업 심사에서 "박스 추천에 무게를 고려했냐"는 질문을 받았습니다. 당시 편성은 치수만 보고 박스 개수가 가장 적은 조합을 골랐습니다.
- **확인 결과**: 다품목 주문 5,000건(주문당 1~10품목, 평균 16.5개)을 기존 방식으로 편성했습니다. 주문 689건(13.8%)에서 택배 접수 한도 20kg을 넘는 박스가 나왔고, 가장 무거운 박스는 45.7kg이었습니다. 이 박스는 그대로 보낼 수 없어 포장 현장에서 다시 나눠야 합니다.
- **요금 구조**: 택배 요금은 세 변의 합 구간과 무게 구간 중 높은 쪽으로 정해집니다. 박스 개수만 세면 무게 때문에 요금이 올라가는 조합도 최적으로 판단합니다.

### 해결 과정

편성 기준을 박스 개수에서 총 택배 요금으로 바꿨습니다. 고른 기준은 두 가지였습니다. 접수 한도를 넘는 박스가 나오지 않아야 하고, 무게 때문에 요금이 오르는 경우도 비교에 들어가야 했습니다.

| 해결 방안 | 장점 | 단점 및 기각 사유 |
| :-: | :-: | :-: |
| 1. 무게 한도만 제약으로 추가 | • 변경 최소<br>• 20kg 초과 박스 방지 | • 무게로 요금 구간이 오르는 조합은 여전히 최적으로 판단 |
| 2. 박스 수와 무게에 가중치를 둔 점수 | • 부피와 무게를 함께 반영 | • 가중치를 정할 근거가 없음 |
| **3. 총 택배 요금 최소 (최종 채택)** | **• 요금이 치수와 무게를 한 금액으로 합침<br>• 한도를 넘는 조합은 후보에서 제외** | **• 요금표가 바뀌면 결과도 바뀜** |

**핵심 설계 결정**

- **요금표를 기준정보로 분리**: 박스 요금은 세 변의 합 구간과 무게 구간 중 높은 쪽으로 계산합니다. 요금표는 DB 기준정보 테이블에 두어, 택배사 요금이 바뀌어도 코드를 고치지 않습니다.
- **무거운 박스를 나누는 탐색**: 기존 탐색은 박스 사이에서 상품을 옮기기만 해 박스 수가 늘어나는 조합을 보지 못했습니다. 상품을 새 박스로 옮기는 경우까지 보게 해 무거운 박스를 나눈 조합도 비교합니다.
- **입구와 출구의 무게 검사**: 상품 하나가 20kg을 넘으면 주문 접수 단계에서 거부합니다. 포장 완료 때는 저울에 잰 무게를 예상 무게와 대조해, 차이가 허용 오차(0.1kg과 예상 무게의 3% 중 큰 값)를 넘으면 완료를 막습니다. 다른 상품이 담기거나 빠진 박스를 출고 전에 잡기 위해서입니다.

### 결론

같은 주문에서 택배로 보낼 수 없는 박스가 사라졌습니다.

| 항목 (다품목 주문 5,000건) | 개선 전 | 개선 후 |
| :-: | :-: | :-: |
| 20kg 초과 박스 | 691개 (주문 13.8%) | **0개** |
| 가장 무거운 박스 | 45.7kg | **20kg 이하** |
| 박스 수 | 5,551개 | 6,036개 |
| 총 운임 (접수 가능 주문 기준) | 3,660만 원 | **3,600만 원 (−1.7%)** |

- **박스 수 증가**: 20kg을 넘던 박스를 나누면서 박스가 8.7% 늘었습니다. 보낼 수 없는 박스를 현장에서 다시 싸는 대신, 편성 단계에서 나눕니다.
- **운임 감소의 출처**: 운임 감소분은 전부 탐색 범위를 넓힌 데서 나왔습니다. 한 박스에 담는 조합과 나누는 조합을 같은 요금 기준으로 비교하면서 더 작은 박스를 찾았습니다. 소품목 주문(1~3품목)에서도 운임이 1.1% 줄었습니다.

## 작성 메모 (Docs 에 옮기지 않음)

- 주문과 상품은 합성 데이터다. 상품은 시연 CJ 식품 11종의 치수를 ±20% 흔들고, 무게는 원 상품의 밀도로 계산했다. 요금표는 파스토 2024 인용 5구간(5,000~9,000원)이고 CJ 공식 요금과 대조하지 못했다.
- 20kg 초과는 다품목 주문에서만 나왔다. 1~3품목 주문의 최대 박스 무게는 15.7kg이었다. 면접에서 "실제 주문 대부분은 단품인데?"라고 물으면: 단품·소품목 주문은 원래 문제가 없었고, 다품목(장보기형) 주문에서 생기는 문제다.
- "무게를 반영해서 운임이 줄었다"로 쓰지 않는다. 무게가 요금 구간을 올린 주문에서는 전후 운임 차이가 0원이었다.
- "현장에서 다시 나눠야 한다"는 추론이다. 20kg 초과 박스의 실제 현장 처리 방식은 확인하지 않았다.
